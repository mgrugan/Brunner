/08Takeaways

What to do with it

Methods

How the analysis was built

A reproducible Python pipeline (python -m commute) reads the workbook, builds the features, runs the statistics and models, writes every number on this page to docs/data/analysis.js, and renders the static figures for the written report.

    Caveats

    143 trips is a small sample. Departure time, wind, elevation, traffic and rain were not recorded, so "direction" absorbs everything that differs between a morning and an evening ride. Six routes share seven trips between them, so route-level conclusions are tentative. Every effect here is an association, not the result of a controlled experiment.
