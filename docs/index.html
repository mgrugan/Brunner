What actually sets the clock?

A bicycle commute measured trip by trip, then put through paired tests, mixed models, splines, Gaussian processes, gradient boosting and conformal prediction. The answer turns out to be four forces: direction, temperature, in-season fitness and, quietly, how often the bike comes out.

Implications

Methods

How the analysis was built

A reproducible Python pipeline (python -m commute) reads the workbook, engineers features, runs the statistics and models, writes every number on this page to docs/data/analysis.js, and renders the static figures for the written report.

    Caveats

    143 trips is a small sample. Departure time, wind, elevation, traffic and rain were not recorded, so "direction" absorbs everything that differs between a morning and an evening ride. Six routes have seven trips between them, so route-level conclusions are tentative. Effects are associations, not controlled experiments.
